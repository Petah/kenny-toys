## UI, icons and audio (supporting packs)

These packs go into other games rather than having one of their own.

| Pack | Use |
|---|---|
| Cursor Pack / Cursor Pixel Pack | Custom cursors per game (e.g. hammer, hand, crosshair). |
| Fantasy UI Borders / UI Adventure Pack / UI Pack - Adventure / Pixel Adventure | Frames and panels for RPG-style games. |
| Mobile Controls | On-screen joystick and buttons for touch play. |
| UI Pack / UI Pixel Pack / UI Pack - Sci-fi | Buttons, sliders and panels; themed menus per game. |
| Board Game Icons / Info | Board and party game UI. |
| Game Icons (+ Expansion / Fighter) | HUD icons: lives, settings, sound, pause. |
| Input Prompts (+ Pixel / 1-Bit) | "Press A / Space / tap" prompts on title screens. |
| Casino Audio | Cards, chips and dice: Blackjack, Ludo. |
| Digital Audio / Sci-Fi Sounds / Retro Sounds 1–2 | Arcade bleeps, lasers, power-ups. |
| Impact Sounds | Hits, footsteps, wood/metal/soft impacts. |
| Interface Sounds / UI Audio | Clicks, toggles, confirms. |
| Music Jingles / Music Loops | Win jingles and background loops. |
| RPG Audio | Knives, cloth, doors, coins. |
| Synth Voice 1–2 / Voiceover Pack (+ Fighter) | Announcer callouts: ready, go, game over, new high score. |
| Fonts (Other) | Kenney Bold / Future, already used by the shared theme. |

The `Archive` folder holds older versions of packs listed above, and `Goodies` holds wallpapers and papercraft. Neither has a game of its own.
